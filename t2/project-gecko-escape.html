COMING SOON · GAME PROJECT

Gecko Escape.

A simple game project developed for a reptile business. More details will be shared when it is ready.

The brief

A small game for a reptile business.

Gecko Escape is in development. This project page will be expanded when the game is ready to share.

Audience: Casual players who enjoy character-led platform games and short interactive challenges.

Purpose: Demonstrate MICA’s ability to design and build a self-contained browser experience.

Status: Coming soon.

Role and constraints

Design and implementation, together.

MICA develops the project as an independent browser game. The interface, visual presentation, character selection, and level interactions are developed together so the game can run in a web browser.

The project is built as a lightweight static web experience. It must remain understandable and playable across pointer, keyboard, and touch input, while supporting distinct characters and environments.

Design decisions

Keep the next action legible.

Character choice

Give each playable character a clear identity and a reason to explore the level.

Responsive controls

Provide input paths suitable for keyboard and touch instead of assuming a desktop mouse.

Distinct environments

Use the level setting to establish a different mood and visual context for play.

Honest release status

The project is still in development. No playable demo is currently available.
